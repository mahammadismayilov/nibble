About Nibble Desktop

Native Desktop Mouse Configurator & Taskbar Battery Meter

Nibble Native Desktop

Version 1.0.4 — System Tray Edition

Nibble Desktop is a native cross-platform application for PAW3395 & PAW3950 gaming mice. It provides WebHID configuration, system tray battery status, and autostart capabilities.
